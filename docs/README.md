# Docs

Project documentation, references, literature notes, and design documents.

## File Naming Convention

```
<type>_<descriptor>.md
```

**Examples:**
- `reference_crazyflie_datasheet.md`
- `design_control_architecture_overview.md`
- `notes_meeting_2026-03-23.md`
- `literature_pid_tuning_methods.md`

## Conventions

- Use Markdown (`.md`) for all written documentation.
- Store PDFs of referenced papers in a `references/` subfolder if needed.
- Keep a running log of design decisions and their rationale.
- Link to relevant simulation or experiment results when discussing findings.
