# Quadrotor Dynamics + CBF Safety Filter Cheat Sheet

## 1. State Vector

[
x = [p^T ;; v^T ;; q^T ;; \omega^T]^T
]

Represents the complete drone state.

| Variable                                | Meaning                               |
| --------------------------------------- | ------------------------------------- |
| (p=[x,y,z]^T)                           | Position in the world frame           |
| (v=[v_x,v_y,v_z]^T)                     | Linear velocity                       |
| (q)                                     | Unit quaternion representing attitude |
| (\omega=[\omega_x,\omega_y,\omega_z]^T) | Angular velocity                      |

**Defense answer:**

> The state vector contains the position, velocity, orientation, and rotational velocity required to fully describe the drone motion.

---

# 2. Motor Dynamics

[
\tau_m \dot{\omega}*i = \omega*{i,cmd} - \omega_i
]

| Variable         | Meaning               |
| ---------------- | --------------------- |
| (\omega_i)       | Current motor speed   |
| (\omega_{i,cmd}) | Commanded motor speed |
| (\tau_m)         | Motor time constant   |

**Defense answer:**

> Motors cannot instantly change speed, so this equation models motor lag.

---

# 3. Rotor Thrust

[
F_i = k_f \omega_i^2
]

| Variable | Meaning                       |
| -------- | ----------------------------- |
| (F_i)    | Thrust generated by rotor (i) |
| (k_f)    | Thrust coefficient            |

**Defense answer:**

> Each rotor produces upward thrust proportional to the square of its rotational speed.

---

# 4. Rotor Torque

[
M_i = k_m \omega_i^2
]

| Variable | Meaning            |
| -------- | ------------------ |
| (M_i)    | Reaction torque    |
| (k_m)    | Torque coefficient |

**Defense answer:**

> Rotor drag generates reaction torques that produce yaw motion.

---

# 5. Total Force

[
f_B=
\begin{bmatrix}
0\
0\
-\sum F_i
\end{bmatrix}
]

**Defense answer:**

> The four propellers combine into a single force acting along the body z-axis.

---

# 6. Total Torque

[
\tau_B=
\sum r_i \times
\begin{bmatrix}
0\
0\
-F_i
\end{bmatrix}
+
\begin{bmatrix}
0\
0\
\sum M_i
\end{bmatrix}
]

| Variable | Meaning                                   |
| -------- | ----------------------------------------- |
| (r_i)    | Rotor position relative to center of mass |

**Defense answer:**

> Thrust offsets generate roll and pitch moments, while rotor drag generates yaw moments.

---

# 7. Position Dynamics

[
\dot p = v
]

**Defense answer:**

> Velocity is the time derivative of position.

---

# 8. Translational Dynamics

[
m\dot v = R(q)f_B + mg\hat z + F_{drag}
]

| Variable   | Meaning                     |
| ---------- | --------------------------- |
| (m)        | Drone mass                  |
| (R(q))     | Rotation matrix             |
| (\hat z)   | Unit vector of world z-axis |
| (F_{drag}) | Aerodynamic drag            |

**Defense answer:**

> This is Newton's second law. The drone acceleration results from thrust, gravity, and aerodynamic drag.

---

# 9. Quaternion Dynamics

[
\dot q = \frac12 q \otimes [0,\omega]
]

**Defense answer:**

> This equation updates the drone attitude from the measured angular velocity.

---

# 10. Rotational Dynamics

[
J\dot\omega =
\tau_B
------

\omega \times (J\omega)
+
\tau_{drag}
]

| Variable      | Meaning         |
| ------------- | --------------- |
| (J)           | Inertia matrix  |
| (\tau_B)      | Control torques |
| (\tau_{drag}) | Rotational drag |

**Defense answer:**

> Rotational acceleration depends on applied torques, gyroscopic effects, and rotational damping.

---

# 11. Drag Models

[
F_{drag} = -K_{drag}v_B
]

[
\tau_{drag} = -k_{rot}\omega
]

**Defense answer:**

> These terms model translational and rotational aerodynamic resistance.

# CBF SAFETY FILTER

---

# 12. Nominal Acceleration

[
a_{nom}
=======

## a_r

## K_p(p-p_r)

K_d(v-v_r)
]

| Variable | Meaning                |
| -------- | ---------------------- |
| (a_r)    | Reference acceleration |
| (p_r)    | Reference position     |
| (v_r)    | Reference velocity     |

**Defense answer:**

> The outer-loop PD controller generates the desired acceleration required to follow the trajectory.

---

# 13. Barrier Function

[
h(p)
====

## (p-p_o)^T(p-p_o)

d_{safe}^2
]

| Variable   | Meaning         |
| ---------- | --------------- |
| (p_o)      | Obstacle center |
| (d_{safe}) | Safety radius   |

**Interpretation**

[
h>0 \Rightarrow \text{Safe}
]

[
h=0 \Rightarrow \text{Boundary}
]

[
h<0 \Rightarrow \text{Unsafe}
]

**Defense answer:**

> The barrier function measures how far the drone is from violating the safety boundary.

---

# 14. Safety Distance

[
d_{safe}=r_{obs}+m_{safe}
]

| Variable   | Meaning         |
| ---------- | --------------- |
| (r_{obs})  | Obstacle radius |
| (m_{safe}) | Safety margin   |

**Defense answer:**

> The safe distance combines the obstacle size and an additional safety buffer.

---

# 15. Barrier Derivative

[
\dot h
======

2(p-p_o)^T v
]

**Interpretation**

[
\dot h>0
]

Moving away from obstacle.

[
\dot h<0
]

Moving toward obstacle.

**Defense answer:**

> The derivative indicates whether the drone is approaching or moving away from the obstacle.

---

# 16. ECBF Constraint

[
Aa \ge b
]

**Defense answer:**

> Only accelerations satisfying this inequality are considered safe.

---

# 17. Matrix A

[
A=2(p-p_o)^T
]

**Defense answer:**

> A is the gradient of the barrier function and points away from the obstacle toward increasing safety.

---

# 18. b Term

[
b=
-2v^Tv
-k_1\dot h
-k_0 h
]

| Term         | Meaning                     |
| ------------ | --------------------------- |
| (-2v^Tv)     | Velocity effect             |
| (-k_1\dot h) | Approach rate effect        |
| (-k_0h)      | Distance-to-boundary effect |

**Defense answer:**

> The term (b) determines how restrictive the safety constraint must be based on speed, approach direction, and remaining safety margin.

---

# 19. Projection-Based Safety Filter

If

[
Aa_{nom}\ge b
]

then

[
a_{safe}=a_{nom}
]

**Defense answer:**

> If the nominal command is already safe, the filter does nothing.

---

Otherwise

[
a_{safe}
========

a_{nom}
+
\frac{b-Aa_{nom}}
{AA^T}
A^T
]

**Defense answer:**

> The filter projects the unsafe command onto the closest acceleration satisfying the safety constraint.

---

# 20. One-Sentence Summary

> The nominal controller generates a desired acceleration, the barrier function evaluates safety relative to the obstacle, and the ECBF minimally modifies the acceleration whenever necessary to guarantee obstacle avoidance.
